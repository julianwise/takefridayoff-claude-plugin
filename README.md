# Take Friday Off for Claude

Wellness product development in Australia: search Take Friday Off’s guides and case studies, check a product’s regulatory pathway, plan a TGA listing, and book a call.

In Claude Code:

```
/plugin marketplace add julianwise/takefridayoff-claude-plugin
/plugin install takefridayoff@takefridayoff
```

The plugin connects Take Friday Off's MCP server (https://takefridayoff.com/mcp, no sign-in) and adds 4 skills: tfo-ad-check, tfo-launch-brief, tfo-pathway-check, tfo-tga-listing-plan. More at https://takefridayoff.com/ai.
